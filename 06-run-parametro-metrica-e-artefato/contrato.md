# Contrato do experimento

Preencha antes de rodar. Cada linha é uma coisa que muda o número se mudar. Escreva os valores, não só o nome do item: o hash, as datas, os números.

Experimento:

Pergunta que ele responde:

| Item | O que fica anotado | Valor nesse experimento |
|---|---|---|
| Código | o arquivo do programa e o hash dele | |
| Dados | o arquivo, o hash, as linhas e o hash de cada parte usada | |
| Divisão | as datas de cada parte, e o que fica fechado | |
| Parâmetros fixos | todos os que não mudam, inclusive os que ficaram no padrão | |
| O que varia | os parâmetros que o experimento testa, com os valores | |
| Semente | as sementes de cada run | |
| Métrica | o nome, a conta, em qual parte e com quantas casas | |
| Artefatos | os arquivos que saem e onde ficam | |
| Ambiente | as versões do Python e das bibliotecas, e o sistema | |
| Regra de decisão | o que precisa acontecer para escolher uma opção, escrita antes de rodar | |
| O que conta como repetir | o que outra pessoa precisa obter para dizer que chegou ao mesmo resultado | |
